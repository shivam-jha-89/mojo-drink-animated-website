# Mojo 3D Drink Animated Website 🥤✨

An interactive 3D animated website built for showcasing a modern beverage brand with immersive visuals and smooth web animations.

## Clone the repository: https://github.com/shivam-jha-89/mojo-drink-animated-website
## Live Demo - https://mojo-drink-animated-website.vercel.app/

## 🚀 Features
- **3D Visuals & Animations:** Engaging 3D product rendering and interactive elements.
- **Modern UI/UX:** Clean, responsive design crafted with Tailwind CSS.
- **Smooth Navigation:** Fast transitions and optimized performance.

## 🛠️ Tech Stack
- **Frontend:** React.js / Next.js, Tailwind CSS
- **3D / Animations:** Three.js / WebGL
- **Deployment:** Vercel

## 📂 Project Structure
```text
mojo-3d-frontend-main/
├── public/         # Static assets and images
├── src/            # Source files (components, pages, styles)
├── package.json    # Project dependencies and scripts
└── README.md       # Project documentation

## Navigate to the project directory: cd mojo-drink-animated-website

## Run the development server: npm run dev

## ⚙️ Getting Started

To run this project locally, follow these steps:

1. **Clone the repository:**
```bash
git clone [https://github.com/shivam-jha-89/mojo-drink-animated-website.git](https://github.com/shivam-jha-89/mojo-drink-animated-website.git)

```


2. **Navigate to the project directory:**
```bash
cd mojo-drink-animated-website

```


3. **Install dependencies:**
```bash
npm install

```


4. **Run the development server:**
```bash
npm run dev

```


5. Open [http://localhost:3000](http://localhost:3000) in your browser to view the app.
